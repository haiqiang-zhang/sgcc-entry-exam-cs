# 国家电网企业文化题库（2027版）

[下载 Anki 卡组](./国家电网企业文化题库（2027版）.apkg?raw=true)

依据《国家电网有限公司高校毕业生招聘考试公共与行业知识题库（2027版）》整理，共 **832 张卡片，一题一卡**。这是独立卡组，无需 Yanki。

- 按“单选题／多选题／判断题 → 部分”分层，题目按原题顺序加入。
- 每次出题随机排列选项，翻面保持同一顺序；卡背以选项内容显示答案。
- 保留政治理论速览、“三先”、企业文化四要素、战略概念对照表等卡背助记。
- 发布包全部为未学习状态，不含个人高亮、学习进度或复习记录。
- 支持 Anki 桌面版及 iPhone／iPad 的 AnkiMobile；选项随机功能无需插件。

下载 `.apkg` 后，在 Anki 中导入；也可以先在电脑导入，再同步到手机。
